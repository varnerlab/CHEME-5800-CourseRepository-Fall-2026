# L7a data

`camera.png` is the 512 × 512, 8-bit grayscale "camera" test image from the
[scikit-image data collection](https://scikit-image.org/docs/stable/api/skimage.data.html#skimage.data.camera).
The photographer, Lav Varshney, released it under CC0, so it carries no copyright
restrictions. The Fun with SVD example loads it from this folder, so the notebook
runs offline.

- Source: `https://gitlab.com/scikit-image/data/-/raw/5c090b56df3988d988ff97928e2ef2d2cbe38e1b/camera.png`
- SHA-256: `b0793d2adda0fa6ae899c03989482bff9a42d3d5690fc7e3648f2795d730c23a`

The 2025 version of this example used the `lake_gray` image from TestImages.jl,
which downloads on first use and lists no license for that image.
