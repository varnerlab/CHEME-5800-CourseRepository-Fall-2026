# UCI AI4I 2020 predictive-maintenance data

`ai4i2020.csv` is the unmodified CSV distributed by the UCI Machine Learning
Repository for the **AI4I 2020 Predictive Maintenance Dataset**.

- UCI dataset page: <https://archive.ics.uci.edu/dataset/601/ai4i%2B2020%2Bpredictive%2Bmaint>
- DOI: <https://doi.org/10.24432/C5HS5C>
- License: Creative Commons Attribution 4.0 International (CC BY 4.0)
- Retrieved: 2026-08-11
- Original filename: `ai4i2020.csv`
- SHA-256: `dc6630cd9b1f0f853922fad78a1b6436570d3f1ec863f1dd5c4340ac56bc8a8e`
- Shape: 10,000 observations and 14 columns; UCI reports no missing values

The course feature matrix excludes both identifier columns and all five
failure-mode target columns. The original CSV is retained without preprocessing.
