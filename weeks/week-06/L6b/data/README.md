# L6b urea-cycle network

`Network.net` is the compact HL-60 urea-cycle reaction network retained from the
CHEME 5800 Fall 2025 FBA lab. It contains five intracellular reactions and fourteen
exchange reactions in the course VFF reaction format. The Fall 2026 implementation
documents its enzyme-capacity assumptions in `Week06Core.jl` and verifies both
steady-state residuals and flux bounds.

Source: CHEME 5800 Fall 2025 `labs/week-6/L6b/data/Network.net`.
