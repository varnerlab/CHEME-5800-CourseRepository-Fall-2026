L11c: Markov Decision Processes

The L11c material comes in three recordings: two lecture videos, followed by a worked example. The lecture and example notebooks are in the L11c folder of the week-11 release.

Lecture, part 1: The problem

What changes when an agent can choose what happens next? In this video, we add actions and rewards to a Markov chain to build a Markov decision process. We define its states, actions, rewards, transition model, and discount factor, and the policy that picks an action in each state. A robot in a small grid world shows how these pieces fit together, and a process operating window shows the same structure in chemical engineering.

Lecture, part 2: The algorithms

How do we find the best action in every state? In this video, we develop two methods. Value iteration updates the value of each state from the values of the states it can reach next, until the values stop changing; the converged values give the optimal policy. Random rollout estimates a state's value by simulating random moves and averaging the discounted rewards. It does not need the transition probabilities, but it measures what random moves are worth, not what the best moves are worth.

Example: Random rollout

Can random moves tell a roomba how to get home? In this example, we build a grid world with a charging station and lava pits as an MDP. We estimate the value of every square with random rollouts, then score each move and pick the best one to get a policy. We follow the policy from a starting square and see where it works and where it fails. In the L11d lab, we compute the optimal policy with value iteration.
