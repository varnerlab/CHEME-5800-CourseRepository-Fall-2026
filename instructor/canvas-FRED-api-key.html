Get a FRED API key for the Week 13 labs

Needed for: the L13b and L13d labs
Cost: free
Time: about 10 minutes

FRED (Federal Reserve Economic Data) is a free database of economic time series from the Federal Reserve Bank of St. Louis. In the L13b lab, you will build a small Julia client for the FRED API. In the L13d lab, you will build an MCP server that calls the same API.

FRED identifies each client by an API key, a string of 32 lowercase letters and numbers. Every request to FRED carries the key. Each student must use their own key, so please get yours before the L13b lab.

Step 1: Create a FRED account

  1. Go to fredaccount.stlouisfed.org/apikeys.
  2. Create a free account, or sign in if you already have one. You can use your Cornell email address.
  3. Confirm your email address if FRED sends you a confirmation link.

Step 2: Request an API key

  1. On the API Keys page, select Request API Key.
  2. FRED asks how you will use the key. A short answer is enough, for example: Class labs for CHEME 4800/5800 at Cornell University.
  3. Agree to the terms of use and submit the request.
  4. Your new key appears on the API Keys page. You can return to this page at any time to view it again.

Step 3: Store the key for the L13b lab

The lab reads your key from a configuration file, not from the notebook. A key typed into a notebook goes to everyone who gets a copy of the notebook. The configuration file stays on your computer.

  1. In the L13b lab folder, open the conf folder.
  2. Copy Configuration-template.toml to a new file named Configuration.toml in the same folder.
  3. In Configuration.toml, replace the text between the quotes on the apikey line with your key, and save the file.

Keep the quotes and leave the baseurl line as it is. The finished file looks like this, with your own key in place of the example key: 

[connection]
apikey = "abcdefghijklmnopqrstuvwxyz012345"
baseurl = "https://api.stlouisfed.org"

Step 4: Reuse the key for the L13d lab

The L13d lab has the same conf folder. Copy your finished Configuration.toml from the L13b conf folder into the L13d conf folder. You do not need a second key.

Keep your key private

Treat your API key like a password. Requests made with your key count against your account.

  • Do not paste your key into a notebook, a Canvas submission, or Ed Discussion.
  • Do not share your key with classmates. Each student needs their own key.
  • Do not commit Configuration.toml to GitHub. The .gitignore file in each conf folder already tells git to skip it.

If you think your key was exposed, delete it on the FRED API Keys page and request a new one. Then paste the new key into your configuration files.

If the lab cannot read your key

The lab checks the configuration file before it calls FRED. If something is wrong, the error message says what to fix. The most common problems are:

  • The file is missing. The file must be named exactly Configuration.toml and sit in the conf folder of the lab. On Windows, check that the editor did not save it as Configuration.toml.txt.
  • The key has the wrong length. A FRED key has exactly 32 characters. Copy the key again, without spaces before or after it.
  • The quotes are missing. The key must sit between the two quote marks on the apikey line.

If you are still stuck, post your question on Ed Discussion or come to office hours. Describe the error message, but do not include your key.
